# 라운지 홈 배너 이미지 규격 (클럽·업체 전달용)

파워플레이 홈(동호회·링크장·경기 탭) 맨 위에는 라운지 스폰서 배너가 나옵니다. 업체가 **커버 이미지**를 올리면 그 이미지를 크게 보여주고, 이미지가 없으면 파워플레이 남색 배경에 로고·이름·설명만 보여줍니다. 오른쪽 위에는 항상 "광고" 표시가 붙습니다.

같은 커버 이미지는 라운지 상세 페이지 맨 위에서도 쓰입니다. 그래서 아래 **안전 영역**만 지키면 두 곳 모두에서 잘리지 않습니다.

## 1. 파일

| 항목 | 권장 |
| --- | --- |
| 크기 | **1600 × 700 px** (가로:세로 16:7). 최소 1200 × 525 px |
| 형식 | JPG 또는 WEBP (PNG·GIF도 업로드는 가능) |
| 용량 | 1MB 이하 권장 (업로드 한도는 5MB) |
| 색 공간 | sRGB |
| 글자 | **이미지 안에 글자를 넣지 않는 것을 권장**합니다. 업체명과 한 줄 설명은 배너 제목·설명 칸에 입력하면 이미지 위에 자동으로 표시됩니다. 작은 화면에서는 이미지 속 글자가 읽히지 않습니다. |

로고는 별도로 올립니다: 정사각형, 최소 160 × 160 px, 투명 배경 PNG 또는 단색 배경.

## 2. 화면별로 보이는 부분

원본 1600 × 700 기준입니다. 모든 위치에서 이미지가 가운데 기준으로 채워지고, 넘치는 부분은 잘립니다.

| 위치 | 화면 비율 | 원본에서 보이는 부분 |
| --- | --- | --- |
| 홈 배너 · 모바일 (화면 폭 640px 미만) | 16 : 7 | 전체 |
| 홈 배너 · 태블릿·PC (640px 이상) | 4 : 1 | 세로 가운데 **400px** (위아래 150px씩 잘림) |
| 라운지 상세 커버 · 모바일 | 약 3 : 2 (높이 256px) | 가로 가운데 **약 1060px** (좌우 270px씩 잘림) |
| 라운지 상세 커버 · PC | 약 3.5 : 1 (높이 320px) | 세로 가운데 약 457px |

## 3. 안전 영역

```
 0                270                                   1330              1600
 ┌──────────────────────────────────────────────────────────────────────┐ 0
 │   (PC 홈 배너에서 잘림)                                  [ 광고 ]     │
 │                                                                      │ 150
 │            ┌───────────────────────────────────────┐                 │
 │  (모바일    │   핵심 영역: 얼굴, 로고, 주요 피사체     │   (모바일       │
 │   상세에서  │   x 270~1330, y 150~390                │    상세에서     │
 │   잘림)     ├───────────────────────────────────────┤    잘림)        │ 390
 │            │ ▓ 업체 로고 · 이름 · 설명이 겹치는 자리 ▓ │                 │
 │            │ ▓ (아래쪽은 어둡게 깔림)                 ▓ │                 │
 │            └───────────────────────────────────────┘                 │ 550
 │   (PC 홈 배너에서 잘림)                                               │
 └──────────────────────────────────────────────────────────────────────┘ 700
```

- **핵심 영역(x 270~1330, y 150~390):** 얼굴, 로고, 가장 보여주고 싶은 장면은 이 안에 둡니다. 모든 화면에서 보입니다.
- **이름·설명 자리(y 390~550, 특히 왼쪽 3/4):** 홈 배너에서는 이 부분이 아래에서 위로 어둡게 깔리고, 그 위에 로고와 업체명·설명이 올라갑니다. 중요한 피사체를 두지 마세요.
- **오른쪽 위 모서리:** 약 160 × 80 px 영역에 "광고" 표시가 올라갑니다.
- **가장자리:** 좌우 270px, 위아래 150px는 화면에 따라 잘립니다. 배경이 자연스럽게 이어지는 사진이 좋습니다.

## 4. 체크리스트

- [ ] 1600 × 700 px, 1MB 이하
- [ ] 이미지 안에 글자 없음 (또는 핵심 영역 안의 큰 글자 한두 단어)
- [ ] 얼굴·로고가 핵심 영역 안에 있음
- [ ] 아래쪽 1/3이 너무 밝거나 복잡하지 않음 (흰 글자가 올라감)
- [ ] 배너 제목과 한 줄 설명을 입력함 (제목·설명이 없으면 홈 배너가 나오지 않습니다)

## 참고 (개발용)

- 구현: `src/components/feedback-banner.tsx`, `src/components/feedback-banner-client.tsx`. 커버(`lounge_businesses.cover_image_url`)가 있으면 이미지형(B), 없으면 남색형(A).
- 홈 배너 비율: `aspect-[16/7]`, 640px 이상 `sm:aspect-[4/1]`. 라운지 상세 커버: `h-64`, `md:h-80` (`lounge-business-detail.tsx`).
- 비율이나 높이를 바꾸면 이 문서의 표와 안전 영역도 함께 고칩니다.
